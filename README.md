# LOAN-APPROVAL-EDA

# 💳 Loan Approval Prediction using Machine Learning

This project predicts **loan eligibility** based on applicant financial and personal details using supervised learning.

---

## 📌 Key Steps

* Data Cleaning & Encoding
* Handling Missing Values
* Feature Scaling
* Model Training & Evaluation

---

## 🤖 ML Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* KNN

---

## 📈 Output

* Predicts whether a loan will be **Approved or Rejected**
* Helps reduce manual decision-making errors

---

## 🎯 Industry Use Case

Banking | FinTech | Credit Risk Analysis
